# Modorch-RS 0.0.1

首个源码版本，面向单进程 Rust 后端应用。框架、Contracts、示例模板与三份 Skill 一并交付；文档与 Skill 为 Candidate，独立 Agent 和跨宿主验收仍未执行。

- 八个框架 crate 统一为 0.0.1，Rust >= 1.85、Edition 2024、MIT；开发阶段的 0.1.0 从未正式发布，本次统一首发版本号。
- 提供 Initiator / Module、显式启用与依赖 DAG、类型化共享服务和租约、Event / Command / Request、四种执行策略、受管任务、CPU / Blocking I/O 资源、检查式关闭和有预算的 Restart。
- 补齐指南、行为 Contracts、公共 Rustdoc、六个标准示例、两个独立模板及文档/Skill 漂移门禁。
- Skill revision 1.0.3，Contract revision 1.0.0；通过 skill-hub 本地登记与归档，Bundle 携带匹配当前源码的指纹、参考、脚本与模板。

验收命令、原始日志与发布限制见[0.0.1 验收证据](../validation/2026-11-02/release-0.0.1/README.md)。旧 0.1.0 开发树的证据保留在原目录，不代替本次重验。依赖版本保持原有锁定，不借版本调整升级第三方依赖。

运行与安装使用[入门指南](../getting-started.md)。外部项目可以使用 tag v0.0.1 的完整源码或源码归档中的路径依赖；本次不执行 cargo publish，不提供未经 Registry 验证的安装声明。

已知限制：没有跨进程或持久化消息、exactly-once、动态插件 ABI；Request 超时不证明回滚，强制取消不证明外部副作用安全退出。GitHub 版本发布不等同于 Documentation & Skills Release Ready；独立 Agent P0 门禁继续返回 Candidate，不使用 fixture 回放替代。
