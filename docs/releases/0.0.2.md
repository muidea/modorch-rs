# Modorch-RS 0.0.2 Candidate

本次 GitHub 预发布将 EventHub Topic Name / Topic Filter 对齐 MQTT 3.1.1/5.0，保留 Event/Command/Request、Destination、Lane、背压、生命周期与组件级去重。八个框架 crate 版本统一为 0.0.2；Contract revision 1.1.0、Skill revision 1.0.5。

- **破坏性变更**：`:id` / `:parameter` 成为字面量；通配订阅 `orders/:id/changed` 迁移为 `orders/+/changed`。
- `+` 接受空层；尾部 `#` 接受零层；根通配不匹配 `$` 起始 Topic，系统树使用 `$SYS/#`。保留空层、大小写和原始 Unicode。
- 所有即时、external、wait 入站统一校验 Name；订阅/初始安装预编译同一 Filter。非法输入 InvalidConfig，合法 Topic 超本地预算 ResourceLimit。协议上限 65535 UTF-8 字节、本地默认预算 1024。
- 同步 Rustdoc、Contract、指南、示例、迁移说明、能力矩阵和三份 skill-hub 管理的 Skill；Bundle 携带对应 0.0.2 框架指纹和便携资源。

升级步骤见[迁移记录](../migration/0.1-development.md)，命令、日志与版本指纹见[本次验收](../validation/2026-11-04/release-0.0.2/README.md)。调整前后[性能测量](../validation/2026-11-04/mqtt-topic-alignment/README.md)保留原始结果：严格校验增加部分查询开销，不能推定统一提速或生产 SLO。

发布范围为 GitHub 源码预发布与 Candidate Skill Bundle；独立 Agent P0 验收仍 NotRun，尚非 Release Ready。未执行 cargo publish，不声明 crates.io / docs.rs 已发布。Topic 标准对齐不提供 MQTT 网络、Broker、QoS、Session、Retained 或共享消费组。旧 v0.0.1 tag 和发布工件保持。
