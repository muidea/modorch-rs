# Modorch-RS 0.0.3 Candidate

本次 GitHub 预发布使普通 Module 可以承载网络入口：新增默认无操作的 Module::activate_ingress，初次启动与监督重建统一入口激活，全部相关 ready 完成后才 listen，全部激活成功后才发布 Ready。八个框架 crate 统一 0.0.3，Contract revision 1.2.0、Skill revision 1.0.7。

- 修复重建激活失败绕过补偿与重试的问题。激活错误或 panic 属于同一次恢复尝试，先停止入口、排空并拆卸，再按累计预算重试；预算耗尽转 FailFast。
- TCP 预绑定使用未 listen 的 TcpSocket；仅延迟 accept 不能阻止握手。HTTP 示例改为普通 Module，管理监听任务与部分启动资源清理。
- 代际失效保证限于任务/服务能力。应用级 EventHub/ExternalEventHub 在重建后仍有效；外部消息经 external() 建立新根准入。
- 保留 Module 的服务发布边界、同 Application 共享 Hub、实例隔离、任务配额和 StopIncomplete 资源屏障；10 个新增真实 TCP 回归覆盖启动、部分激活失败、重试、预算、取消及关闭。

升级：既有 Module 不覆盖新 Hook 可继续使用；覆盖时添加 #[async_trait]。把 setup/start/ready 的监听迁入 activate_ingress；复核宿主对重建激活错误的策略预期。安装绑定 0.0.3 新源码指纹的 Skill 1.0.7 Bundle，详见[迁移](../migration/0.1-development.md)。

[发布验收](../validation/2026-11-06/release-0.0.3/README.md)保存实际命令、版本和日志。发布范围为 GitHub 源码预发布与 Candidate Skill Bundle；独立 Agent P0 验收仍 NotRun，尚非 Release Ready。未执行 cargo publish，不声明 crates.io / docs.rs 发布；不实现 MQTT Broker、QoS、Session 或共享消费组，不作未测量性能承诺。旧 tag 与工件保留。
